# Multi-Agent Textbook RAG with Production Observability

An enterprise-ready AI pipeline designed to parse textbooks, manage semantic workflows with specialized agents, and proactively mitigate RAG failures.

## 🛠️ Tech Stack
- **AI Core:** Python, LangGraph, OpenAI GPT-4o-mini
- **Data Engineering:** PyMuPDF (Layout-aware block and table extraction)
- **Infrastructure:** Docker Compose, Qdrant (Vector Database)
- **Observability & Evaluation:** Arize Phoenix (OTLP Tracing), Ragas (LLM-as-a-Judge validation)
